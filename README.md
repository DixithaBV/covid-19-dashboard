# 🦠 COVID-19 Global Dashboard

Interactive COVID-19 global data explorer built with Python and Streamlit.

## 🌐 Live Demo
[Click here to view the app](https://dixitha-covid-dashboard.streamlit.app)

## ✨ Features
- 🌍 Filter by country and date range
- 📊 5 interactive Plotly charts
- 📈 KPI cards — confirmed, deaths, recovered, death rate
- 📋 Raw data table

## 🛠 Tech Stack
| Layer | Technology |
|-------|-----------|
| Data | Pandas, CSV dataset |
| Charts | Plotly Express |
| App | Streamlit |
| Deployment | Streamlit Cloud |

## 🚀 How to Run Locally
\```bash
git clone https://github.com/DixithaBV/covid-19-dashboard.git
cd covid-19-dashboard
pip install -r requirements.txt
streamlit run app.py
\```
